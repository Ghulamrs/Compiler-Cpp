# Where the audit work stands, and how to pick it up

Written as the session ended, so that the next one starts from fact rather
than from reconstruction. `CLAUDE.md` holds the design record and the status
table; this file holds only what is *in flight* — which branch has what, which
of it is trustworthy, and what to do next.

## The short version

Fable 5 audited this compiler at `29f8dfb`, its findings were fixed, and it
was then asked whether they were fixed **to its satisfaction**. For three
groups the answer was no. It was given a worktree per group and asked to mend
its own findings. One group finished and is merged. Two were stopped
mid-flight when the session ended; their work is saved on branches, unreviewed.

**The pattern worth carrying forward:** eleven findings were properly mended
and eight left a live neighbour of the same fault — [class.copy]/32 where /31
was done, copy *assignment* where construction was done, `new P()` where the
stack temporary was done, a *small* struct returned from a member where the
large one was done, `:0` after an open unit where `:0` after a plain member
was done, the class-layout size where the declarator was done, three floating
lanes where the literal was done. Every fix was correct. Every fix stopped
where its test stopped. Assume the same of anything fixed from here.

incomplete in that one place.

To get a worktree back:

    git worktree add /private/tmp/sem fable/sem-mend
    git worktree add /private/tmp/src fable/src-mend

### Accepted where C++11 refuses

- `const S s;` for a POD with no user-provided constructor — also `const int i;`
- the [over.ics.rank] ambiguity between `f(int)` and `f(const int &)` on an
  lvalue is silently resolved. Note that `f(int)` vs `f(int &)` *is* already
  rejected — find out what distinguishes them before changing anything.
  Probably needs candidate sets rather than a first-match search, which is the
  same change ADL wants; see docs/CONFORMANCE.md

### Recorded, not worked

- two conservative false-refusals in `exactlyADouble` — trailing zeros past 19
  digits, and exactly-representable big integers. The fix text overclaims and
  needs a line either way
- `int i = int();` and a mem-initialiser `: p()` are refused; legal
  accumulation of defaults across redeclarations is refused. All loud, all
  legal C++11
- catching a substitution failure from inside an instantiated class *body* is
  non-conforming — [temp.deduct]/8 immediate context. clang hard-errors where
  this compiler recovers. Outside the audit, noticed in passing

### Two claims never reproduced

Asked for, never received — treat as unproven, not as false:

- an internal-linkage global referenced from a member function failing to
  link. A plain `static int live; T::T(){ live++; }` links and runs correctly
- clang accepting a move-only *parameter* return. clang rejects it here too,
  at the call, since passing a move-only object by value needs a copy

## The blocker that matters most

**The Windows box builds `cxx1-msvc.exe` and is then refused permission to run
it** — `blocked by your organization's Device Guard policy`. All 221 cases
fail with that one message. It needs a policy exception for `C:\cxx1\`, which
is not something this session could do.

Until then every change lands on two boxes, and the Microsoft-ABI half of this
compiler is unverified: `sret-check`, the cl name comparison, and the MASM
output. That leg found two of the ABI faults in this round. Two commits say so
in their first paragraph — `e9cf149` and `912a4bf` — following the precedent
`da6bf71` set.

`tools/windows/sret-check.cmd` now asks the small-struct question as well as
the large one, and `tools/verify-three` expects `17 20 7 19`. The moment that
box runs again, real cl rules on A-01 rather than clang standing in for it.

## How the review was run, if it is worth repeating

Three agents, one per area, each told: a finding counts as mended only if a
**neighbouring shape you did not use the first time** also passes. That single
instruction is what found the eight short fixes; a re-run of the original
programs would have passed all nineteen. Each was also told that declaring
something unsolvable is a legitimate answer, provided it names what would have
to exist first.
